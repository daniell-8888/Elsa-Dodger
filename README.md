# Elsa Dodger

A tiny browser game built with a single index.html file and deployed on Vercel. Move the player, dodge falling blocks, and try to beat the best score. This project is just for fun; nothing serious or production‑grade intended.

## Demo
- Open the deployed site URL after pushing to the connected GitHub repo on Vercel.
- If updates don’t appear, hard‑refresh the page.

## Features
- Pure HTML/CSS/vanilla JS in one file.
- Responsive layout for desktop and mobile.
- Arrow keys or tap/drag to move, Space to pause.
- Increasing difficulty, score tracking, and localStorage “Best” score.
- Player sprite uses image.jpg in the project root.

## Quick start
1. Ensure the repository contains:
   - index.html
   - image.jpg
2. Push to your GitHub repository; Vercel auto‑deploys if connected.
3. Open the deployment URL and play.

## Controls
- Left/Right Arrow: move
- Tap/Drag: move on touch devices
- Space: pause/resume

## Development
- Edit index.html to tweak styles, speeds, or collision rules.
- Replace image.jpg to change the player appearance.
- Commit and push to trigger a new deployment.
